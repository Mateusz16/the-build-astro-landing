# The Build

Demonstracyjna strona firmy remontowo-budowlanej przygotowana jako przykład realizacji oferowanej przez Strona2Zero.

## Technologia

- Astro 7
- TypeScript w trybie strict
- Czysty CSS
- Minimalny JavaScript wyłącznie dla menu mobilnego i demonstracyjnego formularza

## Komendy

```bash
npm install
npm run dev
npm run check
npm run build
npm run preview
```

Formularz działa w trybie demonstracyjnym i nie wysyła danych do zewnętrznej usługi.
